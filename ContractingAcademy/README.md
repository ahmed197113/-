# أكاديمية محاسبة المقاولات (تطبيق أندرويد)

تطبيق تعليمي عربي بالكامل لتعليم المحاسبة من الصفر حتى مستوى الخبير، مع تركيز على شركات المقاولات والأرشفة.

## المحتوى
| المسار | الدروس |
|---|---|
| أساسيات المحاسبة | 12 درساً (المعادلة، القيود، الدفاتر، التسويات، الإهلاك، القوائم، النسب) |
| محاسبة المقاولات | 23 درساً (IFRS 15 ونسبة الإنجاز، المستخلصات، المحتجزات، الدفعات المقدمة، أوامر التغيير، العقود الخاسرة، الباطن، المعدات، الزكاة والضريبة، فاتورة، اعتماد، EVM، الرقابة، دراسة حالة) |
| الأرشفة وتنظيم المستندات | 8 دروس (مدد الحفظ، الأرشفة الورقية، ملف المشروع، تسمية الملفات، DMS/CDE، الأمن والنسخ الاحتياطي، الرقمنة) |
| مهارات المحاسب العملية | 5 دروس (الإقفال الشهري، أعمار الديون والمخصص، العهد والموردون، الموازنات، Excel) |
| القطاعات الأخرى | 3 دروس تأسيسية (تجاري، صناعي، خدمي) |

لكل درس: خريطة ذهنية تفاعلية (تكبير وسحب)، تشبيه من الواقع، مخططات انسيابية ومقارنات وحسابات T، أخطاء شائعة، خلاصة، بطاقات مراجعة، وتمارين قيود تفاعلية.

إضافة إلى: 157 سؤال اختبار مع الشرح، 3 مستويات (مبتدئ/متوسط/خبير)، قاموس 101 مصطلح مع بطاقات مراجعة، خريطة ذهنية للمنهج كاملاً عربي/إنجليزي، بحث شامل، 5 حاسبات (نسبة الإنجاز، المستخلص، الإهلاك، الضريبة، الزكاة)، و35 مصدراً رسمياً (IFRS، SOCPA، ZATCA، الأنظمة السعودية، FIDIC، ISO) مع روابطها.

## الحصول على ملف APK
كل دفعة (push) تُشغّل GitHub Actions: من تبويب **Actions** ← آخر تشغيل لـ «بناء تطبيق أندرويد» ← **Artifacts** ← `ContractingAcademy-apk`.
- `app-release.apk`: النسخة المحسّنة (موقعة بمفتاح تصحيح للتثبيت المباشر؛ استبدل التوقيع قبل النشر على Google Play).

## تعديل المحتوى
المحتوى مكتوب في `content-src/*.py` ثم يُولَّد إلى JSON:
```bash
python3 content-src/build.py
```
السكربت يتحقق من توازن القيود، صحة إجابات الأسئلة، ووجود المصادر.

## البناء محلياً
Android Studio أو: `./gradlew assembleRelease` (يتطلب Android SDK 35 و JDK 17).
