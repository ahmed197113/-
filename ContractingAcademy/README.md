# أكاديمية المحاسب (تطبيق أندرويد)

تطبيق تعليمي عربي بالكامل لتعليم المحاسبة من الصفر حتى مستوى الخبير، مع تركيز على شركات المقاولات والأرشفة.

## المحتوى (118 درساً، 384 سؤالاً)
| الفئة | المسارات |
|---|---|
| ① الأساسيات | أساسيات المحاسبة (12) |
| ② المعايير الدولية | 43 درساً: كل معيار IFRS/IAS ساري + المنشآت الصغيرة والمتوسطة + معايير الاستدامة S1/S2 |
| ③ مجالات المحاسبة | التكاليف (5)، الإدارية (4)، المراجعة (4)، الضرائب والزكاة (3)، الشركات (3)، الحكومية وغير الهادفة للربح (2) |
| ④ القطاعات | المقاولات (23)، التجارية والصناعية والخدمية والعقارية والفنادق والمستشفيات (6) |
| ⑤ مهارات عملية | مهارات المحاسب (5)، الأرشفة وتنظيم المستندات (8) |

لكل درس: جملة تعريف واحدة، «ببساطة»، تشبيه من الواقع، صورة توضيحية للعملية أو أعمدة بالأرقام، خريطة ذهنية تفاعلية، مخططات ومقارنات وقواعد، أمثلة بالأرقام وقيود محاسبية، أخطاء شائعة، خلاصة، بطاقات مراجعة، تمارين قيود تفاعلية، واختبار.

إضافة إلى: تبويب للمعايير مع بحث وتصفية، بنك أسئلة عشوائي، خطة تعلم مقترحة، قاموس 101 مصطلح، 5 حاسبات، و41 مصدراً رسمياً.

## الحصول على ملف APK
كل دفعة (push) تُشغّل GitHub Actions: من تبويب **Actions** ← آخر تشغيل لـ «بناء تطبيق أندرويد» ← **Artifacts** ← `ContractingAcademy-apk`.
- `app-release.apk`: النسخة المحسّنة (موقعة بمفتاح تصحيح للتثبيت المباشر؛ استبدل التوقيع قبل النشر على Google Play).

## تعديل المحتوى
المحتوى مكتوب في `content-src/*.py` ثم يُولَّد إلى JSON:
```bash
python3 content-src/build.py
```
السكربت يتحقق من توازن القيود، صحة إجابات الأسئلة، ووجود المصادر.

## البناء محلياً
Android Studio أو: `./gradlew assembleRelease` (يتطلب Android SDK 35 و JDK 17).
