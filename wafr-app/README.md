# وَفْر — Wafr 🚀

تطبيق أندرويد لإدارة الوَفْرة الشهرية، مبني على فكرة واحدة: **كل مصروف يُوزن، ضروري أم كمالي؟**

## أهم الميزات
- **تذكير كل 5 ساعات** «هل صرفت شيئاً؟» تجيب عنه من الإشعار نفسه: اكتب `25 قهوة` تحت «ضروري» أو «كمالي»، أو اضغط «لم أصرف». لا يصلك في أوقات النوم، ولا يصلك إن كنت سجّلت مصروفاً خلال آخر ساعة ونصف.
- **اختصار في ستارة الإشعارات**: زر «سجّل مصروف» في الإعدادات السريعة يفتح نافذة إضافة فوق أي تطبيق.
- **إشعار ثابت** يعرض «باقي لك اليوم» مع إضافة سريعة بالكتابة.
- **ويدجت للشاشة الرئيسية** بحجمين: كبير (المسموح اليوم + التقدم + زرا ضروري/كمالي) وصغير (رقم اليوم + زر).
- **«المسموح لك اليوم»** يُعاد حسابه يومياً من المتبقي ÷ الأيام المتبقية.
- **دورة الراتب**: الشهر يبدأ من يوم نزول الراتب الذي تختاره.
- **تصنيف تلقائي** من الوصف (بنزين ← مواصلات، قهوة ← مطاعم وقهوة).
- **تحليلات**: مؤشر انضباط من 100، سلسلة أيام بلا كماليات 🔥، رسم يومي، توزيع الفئات، ونصائح ذكية.
- **الخطة**: حدود شهرية لكل فئة وأهداف ادخار.
- خصوصية تامة: البيانات على الجهاز فقط، بلا إعلانات ولا اشتراكات. تصدير CSV متوافق مع Excel.

## البناء
يُبنى ملف APK تلقائياً عبر GitHub Actions (`.github/workflows/wafr-android.yml`) ويُنشر كـ pre-release.
محلياً: `./gradlew assembleRelease` (يتطلب Android SDK 36 وJDK 17).

## البنية
- `data/` — Room (مصاريف، فئات، أهداف، ردود التذكير) + DataStore للإعدادات
- `domain/` — حساب الدورة واللقطة اليومية والمؤشر والنصائح
- `notify/` — الإشعارات والردود المضمّنة وWorkManager
- `tile/` — زر الإعدادات السريعة
- `widget/` — ويدجت Glance
- `ui/` — واجهة Jetpack Compose
