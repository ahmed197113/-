# نظام إدارة المشروعات والمواقع

| الملف | المحتوى |
|---|---|
| `Site_Operations_System.xlsx` | النظام الإلكتروني: لوحة قيادة + 13 سجلاً مترابطاً + طباعة سندات القبض والصرف |
| `Site_Forms_Pack.docx` | 18 نموذجاً ورقياً (استلام موقع ← اعتماد مواد ← توريد ← استلام ← فحص ← مستخلص ← تسليم) |
| `Receipt_Payment_Vouchers.docx` | سند قبض – سند صرف – سند عهدة – تسوية عهدة |
| `System_Guide_and_Ideas.docx` | دورة العمل، الترقيم، الصلاحيات، RACI، مؤشرات الأداء، أفكار التطوير |

إعادة التوليد: `python3 build_ops_system.py` و `node build_forms.js` (يتطلب openpyxl وحزمة docx).
