# فواتير البقالة (المرحلة الأولى)

تطبيق أندرويد بسيط لإصدار فواتير البقالات الصغيرة، يعمل بدون إنترنت.

## المزايا
- **محل مسجّل ضريبياً:** «فاتورة ضريبية مبسطة» + ضريبة 15% + رمز QR بصيغة TLV/Base64 حسب متطلبات المرحلة الأولى (اسم البائع، الرقم الضريبي، الوقت، الإجمالي، الضريبة).
- **محل غير مسجّل:** «فاتورة مبيعات» بدون ضريبة وبدون رقم ضريبي وبدون QR ضريبي.
- أصناف سريعة، ترقيم تسلسلي، إشعار دائن (مرتجع)، ملخص مبيعات اليوم.
- طباعة أو حفظ PDF عبر خدمة الطباعة في أندرويد.
- نسخة احتياطية/استرجاع (نص).
- لا يمكن حذف أو تعديل فاتورة بعد إصدارها؛ التصحيح عبر إشعار دائن.

## التحميل
كل دفع إلى المستودع يبني APK تلقائياً عبر GitHub Actions وينشره في **Releases**.

## ملاحظات
- البيانات محفوظة على الجهاز فقط؛ حذف التطبيق يحذفها، فخذ نسخة احتياطية دورياً.
- المرحلة الثانية (الربط مع منصة فاتورة) غير مشمولة.
