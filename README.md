# موقعي — نظام إدارة مواقع المقاولات

تطبيق ويب متجاوب (موبايل وويب، عربي RTL، يعمل بدون إنترنت كتطبيق PWA) لشركة **الخطوط المعدنية للمقاولات العامة**.

## التشغيل

```bash
npm install
npm start          # http://localhost:3000 — تُضاف البيانات التجريبية تلقائياً عند أول تشغيل
npm test           # الاختبارات
npm run seed       # إعادة البيانات التجريبية (يحذف البيانات الحالية)
```

يتطلب Node.js 22.5 أو أحدث (قاعدة البيانات SQLite مدمجة، لا تحتاج خادماً منفصلاً). البيانات في `data/`.

## الحسابات التجريبية (كلمة المرور لكلها `123456`)

| المستخدم | الدور |
|---|---|
| `gm` | مدير عام |
| `owner` | المالك |
| `finance` | محاسب / إدارة مالية |
| `pm1`, `pm2` | مدير مشروع |
| `sup1` … `sup5` | مشرف موقع |

## الصلاحيات (تُطبَّق في الخادم — `server/permissions.js`)

- **المدير العام**: كل المشاريع والتكاليف، إنشاء المشاريع والمستخدمين، اعتماد المستخلصات. **لا يصرف**.
- **المالك**: يرى كل شيء، يعتمد ويصرف.
- **المحاسب**: يرى كل الحضور والتكاليف، يصدّر الرواتب، يصرف المستخلصات المعتمدة.
- **مدير المشروع**: مشاريعه فقط (العمال، الحضور، البلاغات، المستخلصات).
- **مشرف الموقع**: مشروعه فقط؛ تحضير من داخل نطاق المشروع، تقارير وبلاغات. لا يرى الأجور.

## الأقسام

لوحة التحكم • المشاريع (خريطة ونطاق Geofence) • العمال (QR، نقل مع سجل، تنبيه الإقامة) • الحضور (QR/جماعي، GPS، غياب تلقائي، متأخر، إضافي) • التقارير اليومية (صور مختومة بالتاريخ والموقع، فيديو، صوت، PDF) • البلاغات (إسناد، مهلة، تصعيد تلقائي) • المستخلصات (اعتماد ثم صرف) • التقارير والتصدير (Excel/PDF، رواتب شهرية).

## ملاحظات

- PDF يُنتج من صفحات طباعة عربية (طباعة ← حفظ PDF) لضمان سلامة الخط العربي.
- الإشعارات: داخل التطبيق + Web Push على الجوال (يتطلب HTTPS في الإنتاج).
- الجمعة عطلة: لا غياب تلقائي.
