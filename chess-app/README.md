# أكاديمية الشطرنج الذكية ♞

تطبيق أندرويد عربي بالكامل لتعلم الشطرنج، يعمل دون إنترنت.

## التثبيت على الهاتف (هونر وغيره)
1. افتح صفحة **Releases** في هذا المستودع من متصفح الهاتف.
2. حمّل ملف `ChessAcademy.apk`.
3. افتح الملف، واسمح بـ "التثبيت من مصادر غير معروفة" عند الطلب، ثم ثبّت.

## المحتوى
- **الأكاديمية**: 6 دورات و35 درسًا تفاعليًا (الأساسيات، الافتتاح، التكتيك، أنماط المات، النهايات، الاستراتيجية).
- **الألغاز**: ألغاز محققة بمحرك Stockfish، مع تلميحات وشرح عربي للحل ولماذا هو الأفضل، وتصنيف يتطور معك، ولغز اليوم، وعاصفة الألغاز.
- **العب مع المدرب**: 9 مستويات، مع تقييم كل نقلة (رائعة، أفضل نقلة، خطأ فادح...) وشرح السبب والبديل الأفضل، وكشف تهديدات الخصم.
- **المحلل الذكي**: Stockfish 18 داخل الهاتف مع شرح عربي لأفضل نقلة، ومراجعة المباريات، واستيراد FEN وPGN.
- **الافتتاحات**: 13 افتتاحية مشروحة نقلةً بنقلة مع وضع تدريب.
- **تدريبات**: الإحداثيات، رؤية الحصان، اختبار معلومات، قاموس مصطلحات، إنجازات، ومستويات XP.

## البناء
يبني GitHub Actions ملف APK تلقائيًا عند كل دفع (`.github/workflows/android.yml`).
يدويًا: `cd chess-app && ./gradlew assembleRelease` (يتطلب Android SDK وJDK 17).
