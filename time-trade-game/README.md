# آلة الزمن التجارية ⏳

لعبة أندرويد تعليمية: تسافر بين **مصر الفرعونية** و**روما القديمة** و**بغداد العباسية** وتتاجر.
الربح يأتي من معرفة ما كان وفيراً وما كان نادراً في كل عصر — مع معلومة تاريخية حقيقية لكل سلعة في كل عصر.

## طريقة اللعب
- 15 سلعة × 3 عصور = 45 معلومة تاريخية في «دفتر المعرفة».
- 25 رحلة، لكل رحلة وقود 12 🪙.
- العرض والطلب: كل وحدة تشتريها ترفع السعر، وكل وحدة تبيعها تخفضه.
- أحداث تاريخية عشوائية (فيضان النيل، موكب نصر روماني، قافلة من الصين…).
- أسئلة «حارس الزمن» بمكافآت، وتوسيع المخزن من ورشة الآلة.

## الحصول على APK
كل دفع (push) يبني ملف APK تلقائياً عبر GitHub Actions:
**Actions → Build Time Trade APK → آخر تشغيل → Artifacts → TimeTrade-apk**.
فك الضغط وثبّت `TimeTrade.apk` على الهاتف (فعّل «التثبيت من مصادر غير معروفة»).

## البناء محلياً
افتح مجلد `time-trade-game` في Android Studio، أو:
```
./gradlew assembleRelease
```

## الملفات
- `app/src/main/assets/index.html` — اللعبة كاملة (HTML/JS)، يمكن تجربتها في أي متصفح.
- `app/src/main/java/.../MainActivity.java` — غلاف WebView.
