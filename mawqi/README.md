# موقعي — شركة الخطوط المعدنية للمقاولات العامة

نظام إدارة مواقع المشاريع والعمالة. مبني بنفس طريقة نظام العهد: واجهة ويب ثابتة + خادم PHP
يعمل على استضافة SiteGround المشتركة، وتطبيق أندرويد يتصل بنفس الخادم.

| الجزء | المجلد | التقنية |
|---|---|---|
| خادم الشركة | `server/` | PHP 8 + SQLite (`api.php` و `lib/`) |
| لوحة التحكم (ويب) | `web/` | React + TypeScript، تُبنى ملفات ثابتة |
| تطبيق الجوال | `mobile/` | Expo (React Native) — ملف APK |

## التخزين والأمان
- قاعدة البيانات `mawqi.sqlite` تُحفظ في مجلد `mawqi-data` **بجوار** جذر الموقع (خارج `public_html`)،
  لأن SiteGround تقدّم الملفات الثابتة مباشرة دون المرور على `.htaccess`.
- لا تحذف مجلد `mawqi-data` أبداً؛ فيه كل بيانات الشركة.
- أول فتح للموقع يعرض شاشة «إعداد موقعي» لإنشاء حساب المدير العام (مع خيار بيانات تجريبية).

## المزامنة بين الجوالات واللوحة
الاستضافة المشتركة لا تدعم WebSocket، فكل جوال ولوحة يسأل الخادم كل 8 ثوانٍ عن رقم إصدار
البيانات (`/api/version`) ويعيد التحميل فقط عند تغيّره — أي تغيير يظهر عند الجميع خلال ثوانٍ.

## الإصدارات (GitHub Actions)
- **SiteGround**: كل تحديث ينشئ إصدار `mawqi-php-vN` فيه `mawqi-siteground.zip` — يُرفع ويُفك في جذر النطاق الفرعي.
- **أندرويد**: كل تحديث للتطبيق ينشئ إصدار `mawqi-android-…` فيه ملف APK.

## التشغيل المحلي للتطوير
```bash
cd server && npm run dev        # PHP على http://localhost:8000 (البيانات في server/.dev-data)
cd web && npm install && npm run dev      # http://localhost:5173
cd mobile && npm install && npx expo start
./scripts/package-siteground.sh           # يبني dist/mawqi-siteground.zip
```
