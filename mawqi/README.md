# موقعي — نظام إدارة مواقع المشاريع

ثلاثة أجزاء مربوطة ببعض لحظياً:

| الجزء | المجلد | التقنية |
|---|---|---|
| خادم الشركة | `server/` | Node.js + Express + Socket.IO + SQLite |
| لوحة التحكم (ويب) | `web/` | React + TypeScript |
| تطبيق الجوال | `mobile/` | Expo (React Native) — Android و iOS |

أي تغيير يُسجَّل على الخادم يُرسَل فوراً عبر Socket.IO لكل الجوالات واللوحات المفتوحة،
وكل مستخدم يستقبل فقط تحديثات المشاريع المسموح له برؤيتها.

## التشغيل

```bash
# 1) الخادم (يُنشئ البيانات التجريبية تلقائياً أول مرة)
cd server && npm install && npm start          # http://0.0.0.0:4000

# 2) لوحة التحكم
cd web && npm install && npm run dev           # http://localhost:5173

# 3) تطبيق الجوال (افتحه بتطبيق Expo Go على الهاتف)
cd mobile && npm install && npx expo start
```

في شاشة دخول الجوال اكتب عنوان خادم الشركة، مثل `http://192.168.1.10:4000`.

- إعادة توليد البيانات التجريبية: `cd server && npm run seed`
- عرض التحديث اللحظي: `cd server && npm run simulate` ثم راقب اللوحة والجوال.

## حسابات تجريبية (كلمة المرور `123456`)

| المستخدم | الدور | يرى |
|---|---|---|
| `admin` | مدير عام | كل المشاريع |
| `pm1`, `pm2` | مدير مشروع | مشاريعه فقط |
| `sup1` … `sup5` | مشرف موقع | مشروعه فقط |
| `acc1` | محاسب | كل المشاريع (الحضور والتكاليف) |
