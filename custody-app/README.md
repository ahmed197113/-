# نظام إدارة العهد 2.0

نظام متكامل لإدارة العهد النقدية والعينية للموظفين، مع مراكز التكلفة والتسويات والتقارير. يعمل كتطبيق أندرويد (APK) أو كموقع ويب.

## طرق التشغيل
| الطريقة | متى تستخدمها |
|---|---|
| **على هذا الجوال** | تبدأ فوراً بدون خادم ولا إنترنت؛ البيانات على الجهاز مع نسخ احتياطي |
| **خادم الشركة** | ليدخل كل موظف من جواله وتظهر مصروفاته للمدير لحظياً |
| **تجريبي** | بيانات وهمية للتعرف على النظام |

تشغيل الخادم: `cd custody-app && node server.js` (Node.js 18+، بدون مكتبات) ثم افتح `http://localhost:3000`.
أول دخول يطلب إنشاء حساب مدير النظام. `DEMO=1` لتحميل بيانات تجريبية، `PORT` و `DATA_DIR` للإعدادات.
في المتصفح: `?mode=local` للتشغيل على الجهاز، `?mode=demo` للتجربة.

## المميزات
- **العهد النقدية**: مستديمة (نثرية تُعوَّض) ومؤقتة (لمهمة بموعد تسوية) — صرف، تعزيز، استرداد، تحويل بين موظفين، صرف فرق، حد أعلى لكل موظف.
- **التسوية**: سند تسوية للمصروفات المعتمدة، مع تعويض العهدة المستديمة أو إغلاق العهدة وحساب المردود / الفرق تلقائياً.
- **المصروفات**: مركز تكلفة + بند (رقم حساب) + ضريبة القيمة المضافة + بيانات الفاتورة + صور متعددة / PDF، واعتماد فردي أو جماعي مع سبب الرفض.
- **مراكز التكلفة**: شجرة متعددة المستويات (مشروع / قسم / فرع / مركبة) بميزانيات وتجميع الفروع وتنبيه تجاوز الميزانية.
- **العهد العينية**: سجل أصول، تسليم / نقل / استلام / صيانة / فقد، إقرار الموظف بالاستلام، ونموذج تسليم مطبوع.
- **طلبات العهد** من الموظف وموافقة الإدارة بصرف مباشر.
- **التقارير** (تصدير Excel وطباعة): الأرصدة، كشف حساب، مراكز التكلفة، البنود، سجل المصروفات، أعمار العهد، التسويات، ضريبة المدخلات، الأصول، تفاعل التنبيهات.
- **سندات مطبوعة**: سند صرف عهدة، سند تسوية، نموذج تسليم أصل.
- **الصلاحيات**: مدير النظام، محاسب، موظف — مع سجل عمليات كامل وإشعارات.
- **تنبيه كل 30 دقيقة** خلال الدوام: «هل صرفت شيئاً؟» — في تطبيق أندرويد يصل حتى والتطبيق مغلق.
- **نسخ احتياطي واستعادة** (ملف JSON يشمل المرفقات).

## البنية
- `public/core.js` منطق النظام كاملاً، مشترك بين الخادم والتشغيل على الجهاز.
- `public/local.js` التخزين على الجهاز (IndexedDB).
- `public/app.js` الواجهة. `server.js` خادم HTTP.
- `android/` تطبيق أندرويد يُبنى تلقائياً عبر GitHub Actions وينشر APK في Releases.

## تشغيل خادم الشركة
1. استأجر خادماً سحابياً صغيراً بنظام Ubuntu 22.04 أو أحدث.
2. أضف في إعدادات نطاق الشركة سجل `A` باسم `custody` يشير إلى عنوان IP الخادم (فيصبح `custody.metal-lines.com`).
3. ادخل للخادم ونفّذ:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/ahmed197113/-/ccr-60d78cf9-33quzo/custody-app/deploy/install.sh | sudo bash -s custody.metal-lines.com
   ```
4. افتح `https://custody.metal-lines.com` وأنشئ حساب المدير، وفي التطبيق اختر «الربط بخادم الشركة».

التحديث لاحقاً: أعد تشغيل نفس الأمر. النسخ الاحتياطية اليومية في `/var/backups/custody`.
